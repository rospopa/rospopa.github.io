# Public-site icons

Selected SVG icons from `lucide-static` version 1.51.0, self-hosted under
`/resources/icons/`. See `LICENSE` for the upstream license notices.

Use the `guide-icon` class with explicit width and height, an empty `alt`,
and `aria-hidden="true"` when the adjacent text already explains the icon.
Keep meaningful link and heading text; icons must not be the only label.

Only the icons currently used are shipped. Add further upstream SVG
assets here as needed instead of loading an entire icon font or runtime.
No public page URLs changed, so sitemap, robots, and llms entries are unchanged.
